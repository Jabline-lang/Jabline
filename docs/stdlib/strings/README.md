# Strings Module

String manipulation functions and utilities.

## Files

- `basic.jb` - len, concat, repeat
- `case.jb` - upper, lower, capitalize
- `search.jb` - contains, index, starts_with, ends_with
- `substring.jb` - slice, substring operations
- `split_join.jb` - split(), join()
- `trim.jb` - trim, trim_left, trim_right
- `replace.jb` - replace operations
- `format.jb` - String formatting
